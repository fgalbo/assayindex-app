# Repository provenance

This standalone repository was exported from the reviewed AssayIndex release at
private donor commit `50e45ba2d6251063f4328fd1dfb44c99176caf36`.

The donor Git history was intentionally not imported because it also contains
unrelated portfolio applications and private release artifacts. This repository
begins with fresh history and an allowlisted AssayIndex-only source tree.

Excluded from this export:

- private acquisition runtime and raw source snapshots
- staged candidate artifacts and GTR testing indexes
- credentials and local deployment configuration
- unrelated portfolio, mobile, model, and media projects
- provider-page captures used during private evaluation
